# VOSC Activity 1 – Tic-Tac-Toe

A simple, clean, and fully functional 2-player **Tic-Tac-Toe game** built as part of **VOSC Activity 1 – Prerequisite Activity**.

---

## 📌 Project Description

This project is a classic 3×3 Tic-Tac-Toe web application. It features a modern gaming-inspired user interface with interactive turn tracking, win/draw detection, visual winning combination highlights, and complete game reset capability. 

The application is built using pure web standards with zero external dependencies, frameworks, or libraries.

---

## ✨ Features

- 🎮 **2-Player Gameplay**: Turn-based action between Player X and Player O.
- ⚡ **Automatic Turn Switching**: Seamless transitions between players.
- 🚫 **Move Validation**: Prevents overwriting already occupied cells.
- 🏆 **Winning Detection**: Detects all 8 possible winning combinations (3 rows, 3 columns, 2 diagonals).
- 🤝 **Draw Detection**: Recognizes when all 9 cells are filled with no winner.
- 🌟 **Visual Winning Line Highlight**: Visually glows and highlights the winning 3 cells.
- 🔄 **Restart Game**: Dedicated reset button to restart state without refreshing the webpage.
- 📱 **Responsive Design**: Fully usable across mobile phones, tablets, and desktop displays.

---

## 🛠️ Technologies Used

This project strictly utilizes plain, vanilla web technologies:

- **HTML5**: Semantic structure of the game UI.
- **CSS3**: Modern custom styling, CSS Grid layout, animations, and responsive media queries.
- **Vanilla JavaScript (ES6+)**: Core game logic, DOM manipulation, and state management.

*(No frameworks like React, Vue, or Tailwind, and no backend/Node.js dependencies were used).*

## 🎮 How to Play

1. Player X always starts first.
2. Click any empty cell on the 3×3 grid to place your symbol.
3. Players alternate turns automatically.
4. The first player to align 3 of their symbols horizontally, vertically, or diagonally wins the game!
5. If all 9 cells are filled without a winner, the game ends in a draw.
6. Click the **Restart Game** button at any time to reset the board.
